# Ayman Alrefaee — Portfolio

A calm, professional portfolio built with plain HTML, CSS and JavaScript.

## Included
- Responsive layout for desktop/tablet/mobile
- Warm cream + dark green visual system
- About, Experience, Skills, Projects, Education/Certifications and Contact
- Mobile navigation
- Scroll reveal animations
- GitHub + LinkedIn + email links
- No neon gradients, particles, excessive glassmorphism or AI-style visuals

## Run locally
Open `index.html` directly in a browser, or use:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
1. Add the final CV URL/file to the `resumeBtn` link in `index.html`.
2. Replace/expand Experience with verified internships or work history.
3. Add verified certifications/courses.
4. Add a real profile image if desired by replacing the `.portrait` block.
5. If you want a real contact form, connect it to a backend/form service instead of `mailto:`.

### Custom domain
If you later connect a domain such as `aymanalrefaee.com`, replace the GitHub Pages URL in:
- `index.html` canonical / Open Graph / structured data
- `sitemap.xml`
- `robots.txt`
- `og-image` URLs

Then submit the new sitemap in Google Search Console.
